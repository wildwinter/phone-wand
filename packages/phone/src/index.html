Seeing a security warning?

The relay uses its own certificate. Accepting the warning once is fine. To stop it appearing, install the relay's certificate: download it here, then on iPhone open Settings, General, VPN & Device Management to install it, and Settings, General, About, Certificate Trust Settings to turn on full trust.
